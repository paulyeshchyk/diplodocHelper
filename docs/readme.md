# Документация на базе Diplodoc

Проект представляет собой сборку технической документации с использованием генератора статических сайтов [Diplodoc Platform](https://diplodoc.com/).
Включает кастомные плагины (например, автоматическая вставка `breadcrumb`), поддержку двух языков (`ru`/`en`), локальный просмотр через `HTTP-сервер` и возможность развёртывания в `Docker`.

## Требования к окружению

- **Node.js** 20\+ (рекомендуется LTS)
- **npm** 7\+
- **Docker** (опционально, для контейнеризации)

## Быстрый старт (локальная разработка)

### 1\. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-folder>
```

### 2\.Установка зависимостей

```bash
npm ci
```

Если `package.json` отсутствует или команда не сработала, зависимости не требуются — сборка использует `npx -y @diplodoc/cli`.

### 3\.Сборка документации

```bash
# Очистка предыдущей сборки
npx rimraf build

# Генерация HTML из Markdown (с поддержкой кастомных ресурсов)
npx -y @diplodoc/cli -i ./docs -o ./build --allow-custom-resources

# Внедрение хлебных крошек (breadcrumb)
node ./plugins/breadcrumb/inject-breadcrumb.js

# Удаление временных служебных файлов Diplodoc
npx rimraf build/.yfm build/.yfmignore build/.yfmlint
```

### 4\. Локальный просмотр

#### Вариант A: через простой HTTP-сервер

```bash
npx http-server ./build --port 8080
```

Затем откройте `http://localhost:8080`

#### Вариант B: через скрипт (с автоматическим открытием браузера)

```bash
# Запуск сервера (фоновый процесс)
node .vscode/scripts/start-http-server.js 8080

# Открытие браузера
node .vscode/scripts/open-url.js http://localhost:8080
```

### 5\. Запуск через VS Code (рекомендовано)

Проект содержит предварительно настроенные **задачи** (`.vscode/tasks.json`) и **конфигурации отладки** (`.vscode/launch.json`).


| Действие                                                            | Команда / горячая клавиша                         |
| :------------------------------------------------------------------ | :------------------------------------------------ |
| Сборка документации                                                 | `Ctrl+Shift+B` -\> `1. Собрать документацию`      |
| Локальный сервер\+ открытие в браузере                              | `F5` -\> выберите `2. Открыть (локальный сервер)` |
| Открытие уже собранной документации из файловой системы (`file://`) | `F5` -\> выберите `2. Открыть (локальный файл)`   |
| `Docker`-сборка и запуск                                            | `F5` -\> выберите `8. Открыть (docker)`           |
| Экспорт в`PDF`                                                      | `Ctrl+Shift+B` -\> `7. Экспорт в PDF`             |

Все задачи задокументированы в `.vscode/tasks.json`. Для работы отладки используется заглушка `noop.js`.

## Сборка и запуск в Docker

### Сборка образа

```bash
docker build -t docbuilder .
```

### Запуск контейнера

```bash
docker run -d --name docbuilder -p 5050:5050 docbuilder
```

После запуска документация будет доступна по адресу `http://localhost:5050`

## Использование скриптов для Docker (VS Code)

Задача `8. Открыть (docker)` автоматически:

- Проверяет наличие `Docker` (`0.12 check-docker`)
- Останавливает все конфликтующие серверы (`0.9 stop-all-servers`)
- Собирает образ (`5. docker: build image`)
- Запускает контейнер в отсоединённом режиме (`6. docker: run container (detached)`)
- Открывает браузер с задержкой (ждёт 3 секунды, пока сервер поднимется)

Дополнительные команды:

- Остановка всех серверов (и `HTTP`, и `Docker`) — задача `9. Остановить все серверы`
- Удаление `Docker`-контейнера — задача `10. Удалить Docker-контейнер`

## Экспорт в PDF

1. Убедитесь, что документация собрана в одностраничном режиме:

   ```bash
   npx -y @diplodoc/cli -i ./docs -o ./build --allow-custom-resources --singlePage
   ```

   (задача `0.5 build-singlepage` уже делает это)

2. Сгенерируйте PDF:

   ```bash
   npx @diplodoc/docs2pdf@latest -i ./build --scroll-to-bottom
   ```

   Результат появится в корневой папке (обычно `./build/output.pdf`).

## Настройка и кастомизация

### Тема оформления

Файл `docs/theme.yaml` управляет цветами, логотипом и общим видом.
Дополнительные стили - `docs/\_assets/style/custom.css` и `breadcrumb.css`.

### Языки

Поддерживаются `ru` и `en`. Настройки локализации заданы в `docs/<lang>/index.yaml` и `toc.yaml`.

### Breadcrumb

Плагин `plugins/breadcrumb` автоматически добавляет навигационную цепочку в каждую страницу. Для корректной работы требуется, чтобы в каждой директории с документацией был файл `index.yaml` с полем `title`.

### Участие в разработке

Если вы хотите дополнить или изменить документацию:

- Сделайте `fork` репозитория.
- Внесите изменения в `Markdown`-файлы в папке `docs/`.
- Проверьте результат локально (сборка и запуск сервера).
- Убедитесь, что `breadcrumb` корректно отображается для новых страниц (при необходимости внесите правки в скрипт `inject-breadcrumb.js`).
- Отправьте `Pull Request`.

**При добавлении новых языков или плагинов обновите соответствующие конфигурации и этот README.**

## Устранение неполадок


| Проблема                          | Решение                                                                                                                             |
| :-------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------- |
| npx: command not found            | Установите`Node.js` и `npm`.                                                                                                        |
| Ошибка при сборке`@diplodoc/cli`  | Удалите`node_modules` и выполните `npm ci` заново.                                                                                  |
| Порт`5050` уже занят              | Используйте задачу`9. Остановить все серверы` или вручную node `.vscode/scripts/kill-port.js 5050`.                                 |
| `Docker`-контейнер не запускается | Убедитесь, что`Docker` демон запущен. Выполните `0.12 check-docker`.                                                                |
| `Хлебные крошки` не отображаются  | Проверьте, что в каждой папке есть`index.yaml` с title. Запустите инъекцию вручную: `node plugins/breadcrumb/inject-breadcrumb.js`. |
