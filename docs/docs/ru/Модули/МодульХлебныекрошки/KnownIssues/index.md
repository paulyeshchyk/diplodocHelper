## Известные ограничения

1. **`templateFile` в конфиге не читается** — путь к шаблону захардкожен в `breadcrumb.extractor.js`. Если понадобится альтернативный шаблон, надо править код.
2. **Страницы на 1 уровень от языка пропускаются.** `ru/foo/index.html` breadcrumb не получает: в `generateBreadcrumbScript` срабатывает `parentSegments.length === 0`. Такое поведение не задокументировано — если оно нежелательно, правится в одном месте.
3. **`titleMap` целиком инжектится в каждую страницу.** При большом объёме документации это заметный прирост размера HTML. Потенциально — выносить карту в отдельный статический JSON и грузить клиентом по `fetch`.
4. **Fallback заголовков родителей — `beautify(seg)`.** Если у папки-родителя нет `index.html` (или он вне `titleMap`), в крошку попадает «Beautify Name» от имени папки, а не реальный заголовок.
5. **VS Code и CLI смотрят в разные места.** VS Code-команда ищет `build/` на уровень выше корня воркспейса, а CLI-шаг в `docs-build.js` получает `./build` относительно корня проекта. Если проект открыт как «папка с `docs/` и `build/`», это может выстрелить как «папка не найдена» в VS Code-режиме.
