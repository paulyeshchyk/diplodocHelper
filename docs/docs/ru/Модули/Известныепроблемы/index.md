## Назначение

Один файл — все известные проблемы по всем модулям. Каждая запись — **ссылка** на модуль(и), где проблема проявляется. Из статьи модуля обратной ссылки **нет**: статья описывает «как должно быть», реестр — «что не так».

Когда проблема исправляется — **запись удаляется**. Отдельного статуса `fixed` нет: наличие записи = проблема открыта.

## Легенда

**Тип**:

| Тип         | Что                                                                                       |
| ----------- | ----------------------------------------------------------------------------------------- |
| `bug`       | Код работает неправильно — есть корректный сценарий, но он не выполняется                 |
| `tradeoff`  | Осознанный компромисс — работает «так, как задумано», но пользователь может ожидать иного |
| `gap`       | Не реализовано — обещано/подразумевается, но нет                                          |
| `by-design` | Так задумано — не баг, но легко принять за баг                                            |

**Severity**:

| Severity   | Что                                                                 |
| ---------- | ------------------------------------------------------------------- |
| `critical` | Ломает сборку, теряет данные, выдаёт «успех» при неудаче            |
| `major`    | Неправильный результат или серьёзное неудобство в типичном сценарии |
| `minor`    | Неправильный результат в редком сценарии или косметика              |

## Правила ведения

1. **Одна запись = один корневой дефект.** Три проявления одного дефекта — одна запись (пример: KI-001).
2. **ID сквозной.** `KI-XXX` — единый счётчик. При удалении записи ID **не переиспользуется**.
3. **Модуль — ссылкой.** Если дефект проявляется в нескольких модулях — все ссылки в одной ячейке через запятую.
4. **Кратко — без кода.** Ссылки на функции/файлы — в разделе «Подробнее», если нужны.
5. **Исправили — удалили.** Отдельного статуса `fixed` нет. Запись исчезает.
6. **Раздел «Подробнее»** — только для записей, где строки таблицы недостаточно. Ссылка на раздел — якорем на `#ki-xxx`.
