## Назначение

Слой `client-runtime` — всё, что исполняется **в браузере читателя**, а не на этапе сборки. Сюда попадает:

- интерактив (сворачивание/разворачивание, сортировка таблиц, поиск, pan/zoom);
- достраивание того, что нельзя сделать статически (хлебные крошки появляются после загрузки DOM, потому что зависят от `containerSelector`);
- «оживление» результатов `post-processing` (тултипы на `<abbr>`, подсветка чипов контекста).

Инжектится слой `post-processing` — клиентские скрипты хранятся рядом с модулями-источниками (`*.client.js`) и вставляются на этапе сборки HTML.

## Когда включается

- **На каждой странице** — скрипты, инжектированные в `</body>` или `</head>` (breadcrumb, gosts, footnoteList, core-renderer и т.д.).
- **Лениво** — SVG pan/zoom (`svg-pan-zoom@3.6.1`) грузится с CDN только если на странице есть `gantt-raw-container`.
- **По действию пользователя** — контекстный поиск инициализируется при первом клике по табу «Поиск».

## Состав

- `abbrs.client.js` / `terms.client.js` — тултипы и «ещё/свернуть» для списков вхождений.
- `context-tags.client.js` — теги контекстов на странице.
- `context-search.client.js` — поиск по контекстам (вкладка на странице «Контексты»).
- `gosts.js` — таблица ГОСТов с группировкой, сортировкой, раскрывающимися карточками.
- `footnoteList.js` — сводная таблица сносок с сортировкой.
- `core-renderer.js` — общий рендерер таблиц contentNavigator (периодическая, контекстная, helptag-карты).
- `mermaid.client.js` / `plantuml.client.js` — pan/zoom для диаграмм Ганта.
- `inject-clean-mode.js` — переключение «чистого» режима без навигации по параметру URL.
- `fix-footnote-links.js` — подкручивает якоря сносок.
