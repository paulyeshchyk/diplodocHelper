# Change Log

## [Unreleased]

### Added

- Поддержка нового типа разделов
- Форматирование выделения в YAML (`diplodoc-helper.yaml.format`): Ж / К / М
    - QuickPick с триггерами: `$(check)` — формат уже применён, `$(circle-outline)` — можно применить
    - Toggle-семантика: клик по активному формату снимает обёртку, по неактивному — навешивает
    - Работает только в контексте YAML-value (inline / block-scalar); guard не даёт выйти за границы значения и внутрь HTML-тегов
    - Пункт в контекстном меню редактора: `Diplodoc-Helper → Форматировать выделение (Ж/К/М)`

### Changed

- Улучшена логика переименования папок
- NLS-заголовки для команд `diplodoc-helper.installScripts` и `diplodoc-helper.gost.Add` (ранее — raw-строки на русском, не переводились на английский)

### Fixed

- Исправлена ошибка при перемещении раздела
- `diplodoc-helper.gost.Add` подключён обработчик (`ux_gost_add`); ранее команда присутствовала в манифесте, но клик не работал
